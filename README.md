# 슛 아크 분석

iOS 18+용 SwiftUI 앱입니다. 앨범에서 불러온 농구 슈팅 영상을 기기 내 Vision 프레임 분석으로 처리합니다.

## 사용 순서

1. 앨범에서 슈팅 영상을 선택합니다.
2. `림 지정`을 누르고 림의 중앙을 탭합니다.
3. 청록색 림 표시가 실제 림 폭과 맞도록 조절합니다.
4. `분석`을 누르면 궤적, 입사각, 동적 목표각 및 피드백이 표시됩니다.

## 구성

- `Models`: 정규화 좌표, 림 보정, 결과 모델
- `Services`: 영상 읽기, Vision 궤적·포즈 분석, 물리 연산
- `ViewModels`: 화면 상태와 분석 실행
- `Views`: 영상·림·궤적 오버레이와 결과 UI

동적 목표각은 정식 림 지름 45cm를 기준 척도로 사용하고, Vision 손목 포즈를 릴리즈 높이에 반영한 2D 투사체 근사치입니다. 카메라와 림의 원근이 크거나 림 폭 보정이 부정확하면 거리·속도 수치는 달라질 수 있습니다.
